========================================================================
SlideCraft Studio - Exports Directory
========================================================================

Store your exported presentations and PDF handouts in this directory.

Supported Export Formats:
1. Portable SlideCraft Package (.slidecraft / .json):
   - Contains complete vector slides, transitions, typography, speaker notes,
     and embedded assets.
2. PDF Handouts & Slides (Print to PDF):
   - Click "Export -> Print / Save to PDF" (or Ctrl+P).
   - SlideCraft Studio automatically formats all slides into standard 16:9
     landscape single-page print spreads, hiding all editor tools, rulers,
     and UI elements.
   - Browser Print Recommendation:
     * Destination: "Save as PDF"
     * Layout: "Landscape"
     * Margins: "None"
     * Options: Enable "Background graphics"
3. HTML Standalone Presentation:
   - Export an offline-viewable standalone slide package that can be opened
     in any web browser without needing SlideCraft Studio installed.
