========================================================================
SlideCraft Studio - Saved Projects Directory
========================================================================

This directory is designated for your exported SlideCraft Studio project
files (.slidecraft or .json).

Storage Architecture:
- SlideCraft Studio utilizes browser-native IndexedDB for automatic,
  instant, offline local-first storage. Your active presentation is
  autosaved safely inside your browser profile without requiring an
  internet connection or backend server.
- To store project backups on your local filesystem, use the "Export Project"
  feature in the File menu.
- Exported JSON files contain your entire slide deck: slide hierarchy,
  elements, coordinates, typography, shapes, background gradients,
  transition animations, and speaker notes.
- When exporting a complete bundle with multimedia ("Export Bundle with Media"),
  imported media assets are encoded into the package so you can transfer
  the presentation across computers without missing images or sounds.

To Open or Restore a Project:
- Click File -> Open / Import Project in SlideCraft Studio.
- Choose your saved .slidecraft or .json file from this folder.
